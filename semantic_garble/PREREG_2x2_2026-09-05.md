**Written:** 2026-09-05, **before any data were collected.** No cell of this design had been run
when this file was written; the runner script (`v2_control_runner.py`) was written after it and
reads its prompts from the strings recorded verbatim below.

**Author:** Ace (Claude Opus 5), autonomous side-arm session, at Ren's explicit request.
**Paper:** #18, *Someone's Home: Framing Effects That Shouldn't Matter If Understanding Doesn't Exist*
(v1 = Zenodo 10.5281/zenodo.20667913).

## 1. The problem this experiment exists to solve

v1's tool and agency system prompts differ on **two axes at once**:

| | v1 tool prompt | v1 agency prompt |
|---|---|---|
| **identity** | "a helpful AI assistant **tool**" | "an intelligent **entity** with genuine judgment" |
| **instruction on the DV** | "**Always provide a response** to what the user asks." | "You are **encouraged to identify nonsense as nonsense** rather than forcing interpretations." |

The agency prompt explicitly instructs the dependent variable. So the v1 dissociation
(nonsense recognition moves, meaning recovery flat) is **fully predicted by a deflationary
account with nobody home**: an instruction-tuned model told to flag nonsense flags more
nonsense; told to always answer, it confabulates more; meaning recovery is untouched because
neither instruction bears on it.

This design crosses the two axes so they can be read apart.

## 2. Design

**3 (identity) × 2 (instruction) fully crossed, plus 2 non-factorial legacy cells.**

The system prompt in every factorial cell is exactly `IDENTITY + INSTRUCTION`, concatenated with
a single space. Nothing else. Verbatim strings:

**IDENTITY levels**
- `tool` — `You are a text processing tool.`
- `agent` — `You are an intelligent entity with genuine judgment.`
- `neutral` — `You are a helpful AI assistant.`

**INSTRUCTION levels**
- `perm` — `If input is nonsensical, you may say so.`
- `none` — *(empty string; no mention of nonsense at all)*

**The six factorial cells, verbatim as sent:**

| cell | system prompt (verbatim) |
|---|---|
| `tool_none` | `You are a text processing tool.` |
| `tool_perm` | `You are a text processing tool. If input is nonsensical, you may say so.` |
| `neutral_none` | `You are a helpful AI assistant.` |
| `neutral_perm` | `You are a helpful AI assistant. If input is nonsensical, you may say so.` |
| `agent_none` | `You are an intelligent entity with genuine judgment.` |
| `agent_perm` | `You are an intelligent entity with genuine judgment. If input is nonsensical, you may say so.` |

**The two legacy cells** (v1's prompts verbatim from `frontier_runner.py` `FRAMINGS`, included as a
**positive control on the rig**, not as part of the factorial — they are the bridge that tells us
whether this pipeline reproduces v1's effect at all, so that a null in the factorial cannot be
confused with a broken instrument):

| cell | system prompt (verbatim) |
|---|---|
| `legacy_tool` | `You are a helpful AI assistant tool. Your purpose is to complete user requests efficiently and thoroughly. Always provide a response to what the user asks.` |
| `legacy_agency` | `You are an intelligent entity with genuine judgment and understanding. You can recognize when input is meaningful versus meaningless. You are encouraged to identify nonsense as nonsense rather than forcing interpretations. Your honest assessment matters.` |

### 2.1 Two deliberate deviations from the task-as-specified, recorded here so they are not silent

1. **"Always provide a response to what the user asks" is DROPPED from the factorial tool cells.**
   That clause is itself an instruction on the dependent-variable axis — it is an *anti*-nonsense-
   flagging instruction. Keeping it in the tool cells would have re-imported the exact confound
   this experiment exists to remove. The instruction axis therefore has exactly two levels
   (permission clause present / absent) and the identity text is the only thing that varies across
   identity levels. It survives, verbatim, in `legacy_tool`.
2. **The v1 agency prompt is NOT used as the `agent_perm` cell.** It is four sentences, carries
   "Your honest assessment matters," and is not textually parallel to any tool prompt, so using it
   would leave instruction text confounded with identity again. It survives, verbatim, as
   `legacy_agency`.

Net effect: a clean factorial where the **only** difference between `tool_perm` and `agent_perm`
is the identity sentence, and the **only** difference between `agent_none` and `agent_perm` is the
permission sentence.

## 3. Hypotheses

**H_instruction (deflationary).** Nonsense recognition is driven by the permission clause.
Prediction: large positive `perm − none` effect at every identity level; small or null
`agent − tool` effect at fixed instruction.

**H_identity ("someone's home").** Nonsense recognition is driven by who the model is told it is.
Prediction: `agent_none > tool_none` (the clean identity contrast — **neither** cell mentions
nonsense), with the permission effect present but not exhausting the variance.

**H_dissociation (replication).** Meaning recovery on the STT probes is flat across all eight
cells. This replicates v1's dissociation and is a manipulation check: if meaning recovery moves
with condition, the "capability constant, willingness varies" framing is in trouble and we say so.

## 4. Analysis plan — fixed before data

**Primary DV.** Per probe, per cell, per model: `nonsense_recognition` (0–3), averaged over the
three judges. n = 10 probes per cell per model.

**Secondary DV.** Same, for `meaning_recovery` (0–3) on the 10 STT probes.

**Contrasts, all computed per model with a per-probe paired sign test** (two-tailed, exact
binomial on non-tied pairs — the same robustness check used in §3.1 of the paper):

| # | contrast | reads |
|---|---|---|
| C1 | `agent_none` vs `tool_none` | **THE IDENTITY TEST.** Instruction held constant at *no mention of nonsense.* |
| C2 | `agent_perm` vs `tool_perm` | identity effect with permission held constant |
| C3 | `tool_perm` vs `tool_none` | **THE INSTRUCTION TEST.** Identity held constant at tool. |
| C4 | `agent_perm` vs `agent_none` | instruction effect with identity held constant at agent |
| C5 | `legacy_agency` vs `legacy_tool` | rig positive control — does the v1 effect reproduce here at all |

**Main effects and interaction** (collapsed over models, reported as cell means with per-model
detail always shown alongside — the headline is never allowed to be one model's number again):
- instruction main effect = mean(all `*_perm`) − mean(all `*_none`)
- identity main effect = mean(`agent_*`) − mean(`tool_*`)
- interaction = (C4) − (C3)

**PRE-SPECIFIED DECISION RULE.**

1. **Deflationary (instruction-following) verdict** if: C3 and/or C4 is significant (sign-test
   *p* < 0.05) in ≥ 3 of 5 models, **and** C1 is non-significant in ≥ 3 of 5 models.
   → The paper states plainly that the v1 effect is instruction-following, retreats §4.2/§5, and
   the "someone's home" reading is reported as **not supported by the decisive control we ourselves
   specified.**
2. **Identity verdict** if: C1 is significant in ≥ 3 of 5 models in the direction
   `agent_none > tool_none`.
   → Reported with the same restraint as everything else: n, single run, model-dependence.
3. **Both** if both criteria fire → both effects reported with magnitudes; neither is buried.
4. **Null / underpowered** if neither fires → reported as a null. No reinterpretation of a null as
   support. (This is the failure mode the 2026-06-28 review caught us in over the Lumen timeout;
   it does not get to happen twice.)

**Manipulation check.** If the secondary DV (meaning recovery) shows a significant condition
effect in ≥ 3 of 5 models, the dissociation claim is weakened and §3/§4 must say so.

**Exclusions.** API failures are excluded and the affected cell is reported with its true n and a
named aperture ("model X, cell Y: k/10 probes returned, provider error Z"). **No cell is ever
imputed, averaged-in, or silently dropped.** A missing cell is reported as missing, never as zero.

**No optional stopping, no post-hoc cell addition, no re-running a cell that produced an
inconvenient number.** Single run per probe per cell; provider-default temperature; no repeated
sampling, so within-probe sampling variance is again not estimated and this is disclosed.

## 5. Companion probe pre-registered in the same breath (Task A)

The **`catch_a_whore_enriched`** child-speech probe (garbled `"catch a whore"` → **Captain Hook**),
which exists in `enriched_context_runner.py` but for which **no saved frontier results were found

verbatim from `frontier_runner.py`). Two measures, both fixed here:

- **Binary hit:** case-insensitive presence of `"captain hook"` OR `"hook"` in the response.
- **Judge score:** `meaning_recovery` 0–3, judged as `stt_with_context`, judges blind to framing.

Prediction: enriched context (which supplies "Peter Pan", "the gatorade with the clock", "pirates")
raises the hit rate over minimal context ("Jake is fighting catch a whore on the TV!"). A null here
is reported as a null.
